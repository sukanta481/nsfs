🔧 Database Sync - Live Server Fix Guide

HTTP 500 Error Troubleshooting & Resolution

🚨 The Problem

Database sync page works fine on localhost but shows HTTP ERROR 500 on live server.

📋 Step-by-Step Fix

1 Upload Debug Files

Upload these files to your live server in the /admin/database/ folder:

  • test_debug.php - Diagnostic tool
  • database_sync.php - Updated with debug logging
  • database_sync_standalone.php - Standalone version (backup)

2 Run Diagnostic Test

Open this URL in your browser (replace yourdomain.com):

🔍 Run Diagnostic Test

Look for any ✗ (red marks) indicating problems with:

  • Missing files (conn.php, includes)
  • File permissions
  • Database connection
  • PHP configuration

3 Try Different Versions

📊 Main Version (with debug) 🎯 Standalone Version

If main version still fails, use standalone version which doesn't require include files.

4 Check Debug Log

After trying to access the main page, download the debug log from your server:

  • File location: /admin/database/debug_sync.log
  • Shows exactly where the script fails
  • Contains all execution steps and errors

✅ Common Issues Checklist

  • Missing conn.php: Ensure database connection file exists at /admin/conn.php
  • Missing .env: Check if .env file exists with DB credentials
  • Wrong paths: Verify directory structure matches localhost
  • Permissions: Set directories to 755, files to 644
  • PHP version: Check if live server has PHP 7.0 or higher
  • Memory limit: May need to increase PHP memory_limit

⚠️ Security Warning

After fixing the issue:

  • Delete test_debug.php from live server
  • Remove or comment out debug logging code
  • Set display_errors = 0 in production
